# Be.Techie Notes — Google Drive-powered Study Portal

Minimal, responsive React/Vite portal for **B.Tech 2019 Scheme**, Computer Science and Cyber Security, with S1 & S2 combined, plus S3–S8.

### The Website is Live at : https://be-techie-notes.vercel.app/

### If you find this website usefull give me a ⭐.  

## Project structure

```text
B.Tech Notes/
├── google-apps-script/
│   └── Code.gs           # Read-only Drive catalog API
├── src/
│   ├── api.js            # JSONP client
│   ├── App.jsx           # UI, semester navigation, folder browser
│   ├── main.jsx          # React entry point
│   └── styles.css        # Minimal black/white/orange design
├── .env.example
├── .gitignore
├── index.html
├── package.json
└── README.md
```
